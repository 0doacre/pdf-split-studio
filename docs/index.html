📄 PDF Split Studio
100% Hors-ligne & Sécurisé

Découpez, fusionnez & optimisez vos PDF

Une application de bureau ultra-rapide, élégante et totalement indépendante du cloud. Traitement 100% local avec préservation vectorielle ou compression sur-mesure.

💿 Télécharger l'Installeur (.MSI) (40 Mo) 🧳 Version Portable (.ZIP) (Sans droits admin)
Dépôt GitHub 🏷️ Notes de version v1.0.0
✂️
6 Modes de Découpe
Page par page, par paquets réguliers de N pages, en X parties égales, par plages précises (ex: 1-3, 5), points de rupture ou sélection interactive sur grille.
💎
Qualité Originale ou Compression
Préservez 100% de la fidélité vectorielle originale sans perte, ou activez l'optimisation pour réduire drastiquement la taille du fichier (DPI et JPEG ajustables).
🔗
Fusion Complète (Merge)
Ajoutez plusieurs PDF, réorganisez-les facilement à la souris, appliquez des filtres de pages par document et combinez-les dans un fichier unique.
🔒
Confidentialité & Sécurité Totale
Aucune connexion externe. Nettoyeur intégré de métadonnées invisibles (auteur, logiciel, dates) et chiffrement fort AES-256 avec mot de passe.
🔄
Organiseur Visuel & Rotation
Génération de miniatures instantanées (pypdfium2), rotation des pages par pas de 90° et aperçu plein écran par simple clic.
⚡
Export Automatique Intelligent
Enregistre automatiquement dans le dossier du fichier source (avec sous-dossier dédié propre) ou dans un dossier personnalisé, avec ouverture directe dans l'Explorateur Windows.

Démarrage en 3 étapes

Clonez le projet et lancez-le en un double-clic sous Windows.

# 1. Cloner le dépôt
git clone https://github.com/0doacre/pdf-split-studio.git
cd pdf-split-studio

# 2. Installer les dépendances hors-ligne
pip install -r requirements.txt

# 3. Lancer l'application
python app.py (ou double-cliquer sur Lancer_PDF_Split.bat)
